# AI Frontend Generator Studio

## What it does

This is a Vite + React web application for generating UI components and interfaces with AI assistance. It provides:
- Interactive component builder
- Motion and animation support
- Lucide React icons integration
- Responsive design tools

## How it works

1. Vite development server provides hot module reloading
2. React components render interactive UI
3. Framer Motion handles animations
4. Lucide provides icon library
5. CSS styling for responsive layout

## Setup

From the `FrontendGeneratorStudio` folder:

```powershell
npm install
```

## Run (Development)

```powershell
npm run dev
```

Server runs on `http://localhost:5173` (Vite default)

## Build (Production)

```powershell
npm run build
```

Creates optimized bundle in `dist/` folder.

## Preview Built App

```powershell
npm run preview
```

Serves the production build locally.

## Project Structure

- `src/App.jsx` - main React component
- `src/styles.css` - global styles
- `index.html` - entry point
- `dist/` - production build output

## Features

- React with Vite for fast development
- Framer Motion for smooth animations
- Lucide icons for UI elements
- Hot module reloading (HMR)
- CSS-based responsive design

## Notes

- Requires Node.js and npm
- On Windows, ensure npm is available (use `npm.cmd` if needed)
- Development server includes hot reload
